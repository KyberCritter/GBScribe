# GBScribe

A homebrew word processor and pixel-art tool for Game Boy hardware that prints to a real
Game Boy Printer.

By Scott Ratchford — [scottratchford.com](https://scottratchford.com)

> **Status: not yet implemented.** Design is complete and approved; see
> **[PLAN.md](PLAN.md)**, which is the authoritative document for this project.
> Read its Context section before writing any code — the target platform is deliberately
> *not* the obvious one, and the reason matters.

## Why it's a GBA app, not a Game Boy Color app

The target hardware is a Game Boy Advance running an **EZ-Flash Omega Definitive Edition**.
That cart runs `.gb`/`.gbc` files through **Goomba Color**, a software emulator on the GBA's
ARM CPU, which has no serial link implementation — so a Game Boy Color ROM on this cart
**can never drive the printer**, the one feature the whole project exists for.

GBScribe is therefore a **native GBA application**, and it talks to the Game Boy Printer by
bit-banging the link port in general-purpose GPIO mode. Full reasoning, protocol details and
timing constraints are in [PLAN.md](PLAN.md).

## Features

- WYSIWYG text editor with an on-screen QWERTY keyboard, rendered at true print width
- Full ASCII plus arrows, geometric shapes, and box-drawing characters
- Word wrap (mid-word or post-word) and explicit line breaks
- Pixel-art drawing mode with a built-in stamp library
- 8 save slots, each holding a document or a drawing
- Prints documents, drawings, and a QR code to a real Game Boy Printer
- Live printer-connected detection on the title screen

## Layout

```
src/        application source
  printer/  GB Printer driver — gbp_packet.c is portable C and MUST stay
            free of GBA headers, so it compiles for the host test harness too
  core/     document model, layout/wrap engine, character set
  ui/       title, menus, editor, drawing, settings, credits
  storage/  save slots (FLASH1M, with an SRAM fallback)
  gfx/      generated by grit — do not hand-edit
assets/     source art, font, music
tests/host/ host-side unit tests and the printer decode harness
tools/      build scripts, QR generation, font export
LICENSES/   dependency license texts, surfaced in the in-app Credits screen
.claude/    Claude Code config; resources/ holds vendored technical documentation
```

## Building

Requires **devkitPro / devkitARM** (which also supplies `make`), plus **libtonc**, **grit**
and **Maxmod**. Emulator testing uses **mGBA**. Nothing is set up yet — this is Milestone 0
in [PLAN.md](PLAN.md).
