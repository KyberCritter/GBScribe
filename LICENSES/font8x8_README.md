# font8x8

The GBScribe screen/print font is derived from dhepper/font8x8
(https://github.com/dhepper/font8x8), 8x8 monochrome bitmap fonts by
Daniel Hepper <daniel@hepper.net>, based on work by Marcel Sondaar
(International Business Machines public domain VGA fonts).

License: **Public Domain**

Arrows, shapes, and tool-icon glyphs were authored for GBScribe
(see tools/mkfont.py).
